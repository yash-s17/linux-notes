Day - 1


echo
meaning : prints text on the terminal
example : echo "Hello World" print Hello World

whoami
meaning : shows the currently logged user
example : whoami      , then it will show your user name

id
meaning : shows the detailed information about the current user
example : id          , then you will see uid (user id) , gid (group id) , groups

id -un
meaning : shows only user name
example : id un       , then you will see only username

id -u
meaning : shows only uid
example : id -u       , then you will see your uid
